# Documentation index

Fifteen documents, grouped by what you are trying to do. Start with the row that
matches your reason for being here.

| If you want to... | Read |
| --- | --- |
| Understand the claim | [WHITEPAPER.md](WHITEPAPER.md) |
| Judge whether the claim holds | [REVIEWER_GUIDE.md](REVIEWER_GUIDE.md) |
| Know what is *not* true yet | [STATUS.md](STATUS.md) |
| Run it | [GETTING_STARTED.md](GETTING_STARTED.md) |

## Understanding it

- [WHITEPAPER.md](WHITEPAPER.md) — the v1 design paper: thesis, system model,
  mechanisms, evaluation, novelty, limitations.
- [ARCHITECTURE.md](ARCHITECTURE.md) — boot flow, process model, IPC, service
  registry, the user-space driver path, package lifecycle; with the Mermaid
  [diagrams](ARCHITECTURE.md#diagrams) and the
  [repository layout](ARCHITECTURE.md#repository-layout).
- [RELATED_WORK.md](RELATED_WORK.md) — where Dezh sits in the literature
  (capabilities, DIFC/provenance, sagas), what is reused, and the precise novelty
  claim.
- [SECURITY_MODEL.md](SECURITY_MODEL.md) — the
  [threat model](SECURITY_MODEL.md#threat-model) first (it scopes every other
  claim), then the [enforcement model](SECURITY_MODEL.md#enforcement-model):
  capability boundaries, the bitmask-vs-object-capability question, revocation.
- [SUBSYSTEMS.md](SUBSYSTEMS.md) — designs that carry their own trust argument:
  [Marz](SUBSYSTEMS.md#marz-guarded-egress), the guarded egress boundary, and
  [package signing](SUBSYSTEMS.md#package-signing).

## Judging it

- [REVIEWER_GUIDE.md](REVIEWER_GUIDE.md) — what to inspect and in what order,
  [how to run each demo](REVIEWER_GUIDE.md#running-the-demos), and the
  [FAQ](REVIEWER_GUIDE.md#faq).
- [STATUS.md](STATUS.md) — one honest page of what is and is not true today.
- [transcripts/](transcripts/) — captured output from real runs:
  [riscv64](transcripts/riscv64.md), [agent-f1](transcripts/agent-f1.md),
  [overnight](transcripts/overnight.md). These files are **generated by the
  kernel under QEMU**, not written by hand; `tools/demo/` regenerates them in
  place.
